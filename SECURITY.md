# WireNet Security

The previous FRP-oriented security content did not describe the repository and must not be used operationally.

The current authoritative security baseline is [WireNet/WIRENET_SECURITY.md](WireNet/WIRENET_SECURITY.md). It defines node enrollment, mTLS, least privilege, private-backend firewall policy, audit logging, safe configuration apply/rollback, and update requirements.

The current code is not approved for production deployment; see the [gap analysis](WireNet/WIRENET_GAP_ANALYSIS.md).
