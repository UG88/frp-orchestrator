# .ai Knowledge Base — FRP Gateway Orchestrator

This `.ai` directory contains context, invariants, networking models, and rules for AI coding assistants working on the **FRP Gateway Orchestration System**.

- [`testing.md`](file:///testing.md): Automated testing conventions and integration test guidelines.
- [`troubleshooting.md`](file:///troubleshooting.md): Diagnosing common issues and running `frpctl doctor`.
- [`decisions/`](file:///decisions): Architecture Decision Records (ADRs).
- [`changelog/`](file:///changelog): Log of AI modifications and architectural updates.
- [`skills/`](file:///skills): Workflows and operational skill guides.
