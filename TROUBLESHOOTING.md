# WireNet Troubleshooting

Do not run legacy FRP commands, deleted shell scripts, HAProxy/PROXY Protocol workarounds, firewall flushes, or destructive auto-repair commands from historical documentation. They conflict with the transparent-routing design and can remove management access or client source-IP preservation.

Use the [operations reference](WireNet/WIRENET_OPERATIONS.md), [networking reference](WireNet/WIRENET_NETWORKING.md), and [migration stop conditions](WireNet/WIRENET_MIGRATION.md) instead. The present implementation has not passed the required integration tests and is not a production deployment procedure.
